# engineering-case-studies
Collection of small engineering case studies focused on data analysis and physics based investigations.

Engineering Case Studies
This repository contains a collection of small, self‑contained engineering investigations. Each case study focuses on data analysis, signal processing, and physics‑based reasoning — the same skills used in motorsport, vehicle dynamics, and mechanical engineering.

The goal of this repo is to demonstrate:
 -structured engineering problem‑solving
 -clear documentation and reproducible workflows
 -practical use of Python for analysing real-world data
 -interpretation of results in a physics context

Each case study lives in its own folder with:
 -a dedicated README
 -source code
 -data files
 -plots

Current Case Studies
1. Phone Drop Impact Analysis
A time-series analysis of accelerometer data recorded during multiple phone drop tests. Includes:
 -peak detection
 -time alignment
 -averaging across experiments
 -sensor bias identification and correction
 -physics interpretation

2. Barcelona Laptime Analysis
A G-G diagram and analysis of acceleration data recorded during a lap of the Circuit de Barcelona-Catalunya. Includes:
-scatter plot generation
-logical indexing
-bar chart generation
-motorsport-relevant interpretation of IMU data
